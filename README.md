# JT Electrical: a Stapled. website concept

A website design concept by [Stapled.](https://stapled.co.uk) for JT Electrical, West Yorkshire. The business has not yet reviewed or approved it. Images are labelled samples, and the enquiry form is a preview that sends and stores nothing.

Requires Node 22.12 or newer. Astro is pinned to `~7.3.8` because 7.4 raises the Node minimum.

```sh
npm install
npm run dev       # http://localhost:4321/
npm run build     # static output in dist/
npm run check     # Astro and TypeScript checks
```

Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
